# 💙 ZXC HUB

### NEXUS ULTIMATE — v20.1.5

A mobile-oriented Roblox UI prototype with a black and electric-blue theme.

## ✨ Features

- Modern dark neon interface
- Floating ZXC button
- Minimize and close controls
- Dashboard navigation
- FPS monitoring
- Camera FOV controls
- Character information
- Mobile touch-friendly layout

## 📂 Project Structure

- `ZXC-HUB.lua` — Main interface prototype
- `modules/Dashboard.lua` — Dashboard utilities
- `modules/Performance.lua` — FPS and device monitoring
- `modules/Visual.lua` — Camera and visual utilities
- `modules/Character.lua` — Character information
- `modules/Settings.lua` — Theme and preferences
- `assets/README.md` — Asset documentation

## ⚠️ Compatibility

This project is a UI prototype. Compatibility depends on the
Roblox execution environment.

Uploading the source to GitHub does not execute it automatically.
The separate modules must be integrated before their functions
are available through the main interface.
